## Publish with GitHub Pages
1. Create a public repository on GitHub.
2. Upload all contents while preserving the folder structure.
3. Open Settings → Pages.
4. Select Deploy from a branch, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish. The project demo links on the portfolio will open the folders' `index.html` pages.

The salon booking page is a front-end demo and stores sample bookings in the current browser only. It does not use a backend or create real appointments.


Projects section: swipe/scroll horizontally across all three project cards. Use Previous/Next controls on desktop or swipe on mobile. All projects share the same showcase-card layout.

## Mock interview video
- The portfolio includes a Mock Interview section with a built-in video player.
- To display your recording, place your video in the same folder as `index.html` and name it `mock-interview.mp4`.
- If the video file is not present, the portfolio displays a designed placeholder instead. Keep the video file size reasonable for GitHub repository limits; a compressed MP4 is recommended.

## Certificates
- The seven certificates are organized in a swipeable horizontal carousel with Previous/Next controls.
- Click any certificate card to open its full-size preview. All certificate images are stored in `certificates/`.
